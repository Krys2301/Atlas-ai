A.T.L.A.S v1 — IA locale iPhone

Moteur : WebLLM
Modèle : Llama-3.2-1B-Instruct-q4f16_1-MLC
Le modèle est exécuté dans le navigateur avec WebGPU. WebLLM documente cette exécution locale sans serveur d'inférence.

Installation :
1. Héberger ce dossier sur une URL HTTPS.
2. Ouvrir l'URL avec Safari sur l'iPhone.
3. Partager -> Ajouter à l'écran d'accueil.
4. Au premier lancement, télécharger le modèle en Wi-Fi.
5. Les conversations sont conservées dans le stockage local du navigateur.

Pré-requis conseillé : iOS 26 / Safari 26 ou supérieur, car WebGPU est pris en charge par Safari sur iOS 26.

Important :
- Le premier téléchargement nécessite Internet.
- Le modèle est ensuite mis en cache par WebLLM.
- Les performances et la quantité de mémoire disponible dépendent de l'iPhone et d'iOS.
- Ce n'est pas encore une application native signée App Store.
